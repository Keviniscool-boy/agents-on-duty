# 06 · 用户操作手册

面向最终用户与演示讲解人。系统地址：`http://<部署主机>:8080`。

## 1. 角色一览

| 角色 | 能做什么 | 入口 |
|---|---|---|
| 普通用户 | 聊天咨询、查订单、申请退款、转人工、查看我的工单 | 顶部：订单售后 / 会话 |
| 客服（agent） | 普通用户全部能力 + 客服工作台（退款审核、人工工单）+ 运维面板 | 顶部多出：客服工作台 / 运维面板 |
| 管理员（admin） | 客服全部能力 + 管理员工作区（账号角色、全量数据、审计） | 顶部多出：管理员 |

> 注册账号默认普通用户；管理员用命令行将指定账号提升为客服/管理员。

## 2. 普通用户

### 咨询问题
1. 登录后直接在输入框提问（Enter 发送，Shift+Enter 换行）。
2. 界面实时显示处理阶段（判断问题类型 → 查询知识库 → 合规检查…）。
3. 政策类回答附带来源片段（如 `POL-AFTER-MVP-001 v1.0 §无理由退货`）。
4. 快捷按钮（退货政策 / 我的订单 / 开户流程）点击即发送。
5. 查询订单时，回复下方会显示**订单卡片**（商品、状态、金额、签收时间）。

### 转人工（重点）
- 直接发送：**"转人工"、"人工客服"、"找人工"、"转接人工"** 等。
- 系统**立即**创建工单并回复工单编号与状态（通常 1 秒内，无需排队等待模型）。
- 同一会话内重复发送不会重复建单，会返回已有工单。

### 查看工单进度与客服对话
顶部「订单售后」→ 拉到底部「**我的工单**」：编号、状态（待处理/处理中/已解决）、
创建时间、处理客服。点「**查看对话 / 追问**」可以：
- 查看客服的回复（回复会出现在这里，无需刷新其他页面）；
- 继续追问或补充说明（发送后客服在工作台可见）。

### 申请退款
1. 「订单售后」→ 我的订单 → 已签收订单点「申请退款」（已取消订单不支持，会显示提示）。
2. 选择售后类型（无理由退货 / 商品质量问题）、填写原因（≤500 字）→ 提交。
3. 状态含义：待人工审核 → 客服可能要求补充信息（在申请卡片里提交）→ 已批准/已拒绝/已完成。
4. 随时可「撤回申请」。

### 失败了怎么办
- 发送失败时消息**不会丢**：输入保留、显示错误原因与「重试上一条」按钮。
- 会话等待人工审核期间不能发新消息（409 提示），按提示先处理售后申请或等待恢复。

## 3. 客服（agent）

### 处理退款审核
1. 顶部「客服工作台」→「退款申请」队列 → 点击申请查看详情
   （用户会话历史、Agent 摘要、工具结果、暂停状态）。
2. 决定：批准 / 拒绝 / 要求补充信息（必填追问内容）。
3. 批准/拒绝后系统自动恢复该用户的会话并把结果写入其历史；
   若恢复失败（网络等），使用「重试恢复」。
4. 用户提供补充信息后工单回到待审核，可再次决定。

### 处理人工工单
1. 「客服工作台」→「人工工单」队列（用户转人工的请求都在这里，含客户名）。
2. 点击工单 → 在「工单对话」里查看客户消息并**回复客户**（客户在"我的工单"对话里可见）→ 「开始处理」→ 处理完成点「标记已解决」。
3. 用户侧"我的工单"实时可见状态与处理客服。

### 运维面板
顶部「运维面板」：MCP 工具清单、Agent 运行指标（服务重启后计数归零）。

## 4. 管理员

「管理员」工作区五个页签：
- **概览**：退款状态分布、待处理/失败工单、账号分布。
- **账号**：用户列表，下拉直接变更角色（不能移除最后一名管理员）。
- **退款工单**：全量退款数据（状态过滤、分页）。
- **运行记录**：每次 Agent 运行的节点/工具/模型明细（按 trace 深入）。
- **操作审计**：角色变更、合规命中（只记类型不记原文）、工具调用、售后操作。

## 5. 常见问题

| 问题 | 答案 |
|---|---|
| 回答说"知识库没有相关信息"？ | 政策有版本与有效期，超范围问题系统宁可拒答并建议转人工，不会编造 |
| 转人工要多久回复？ | 工单立即生成；人工处理时长取决于客服，可在"我的工单"跟踪状态 |
| 退款批准了钱到账了吗？ | 演示系统不涉及真实资金；"已批准"仅代表审核通过 |
| 登录过期？ | 令牌默认 60 分钟；界面会自动弹出重新登录 |
| 发送显示"会话正在处理其他请求"？ | 上一条还在处理中，稍候再发 |
