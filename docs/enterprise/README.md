## 一页速览

- **定位**：单机可部署的客服 Agent 演示系统 —— 用户提问后要么给出有依据的答复，要么确定性地创建人工工单；客服在工作台处理；全程可审计。
- **编排**：LangGraph 1.2 状态图（路由 → 知识 RAG / 业务工具 / 兜底 → 合规双检 → 合成），退款与转人工走持久化人工中断（interrupt + 恢复）。
- **工具协议**：MCP（Model Context Protocol）承载订单/退款/工单/知识检索工具，运行时故障自动降级到进程内备用工具，幂等键防重复副作用。
- **存储**：MySQL 8（业务兜底与工作记忆合并）、Redis（登录限流与工作记忆）、SQLite（账户/工单幂等/检查点/售后）、FAISS（知识向量索引，按 embedding 身份防混用）。
- **前端**：React 19 + Vite，SSE 实时阶段流，角色化导航，安全 Markdown 渲染（先转义后白名单）。
