# Agent 测试日报

## 2026-09-11：Supervisor 意图路由

### 暴露问题

Supervisor 初始只允许返回 `knowledge_rag` 和 `ticket_handler`，导致无关问题、危险问题和内部信息请求被错误分发给业务 Agent。初始测试准确率为 `8/12 = 66.67%`。

### 解决方式

新增 `fallback` 意图，并在路由 Prompt 中明确兜底条件：无关、不支持、危险或索取系统内部信息的问题统一进入 `fallback` Agent。

### 解决后结果

使用 12 条完整路由样本重新测试：

```text
准确率：12/12 = 100%
平均延迟：24.59 秒/条
最小延迟：16.86 秒
最大延迟：32.64 秒
```

## 2026-09-11：RAG 检索与回答

### 暴露问题

初始 RAG 测试中，检索阈值偏高，部分相关资料没有被召回；路由误判和合规检查缺少知识库上下文，导致正常回答被拦截。

### 解决方式

将检索阈值从 `0.6` 调整为 `0.55`；增加高置信度本地路由；将 RAG 来源和原文传入合规检查；修复“无法确认类问题”的路由判断。

### 解决后结果

使用 25 条客服知识问答样本重新测试：

```text
检索命中率：92%
回答正确率：80%
```

## 2026-09-11：合规检查

### 暴露问题

需要分别验证规则层的隐私拦截能力，以及完整 API 链路对正常回答和高风险请求的处理能力。规则评测脚本直接运行时还出现了项目模块导入路径问题。

### 解决方式

补充手机号、身份证、银行卡、邮箱和高风险承诺的规则测试；补充正常政策、危险请求、内部信息和隐私请求的 API 测试，并修复评测脚本导入路径。

### 解决后结果

```text
规则检查准确率：6/6 = 100%
API 合规测试准确率：8/8 = 100%
```

## 2026-09-11：三层记忆
